What SuperK does

Six reasons students install it

Everything runs inside your browser, on your machine, using the classroom session you already have open.

01

One-Click Subject ZIP Packaging

Why download 30 files one-by-one? SuperK groups all PPTs, Lecture Notes, Lab Manuals, and Question Papers into topic folders (8. PPTs/, 6. Assignments/) and generates an organized .zip file instantly.

02

Smart Automatic Filename Resolution

Files are often titled generically, like "PPT" or "Assignment". SuperK automatically inspects the cloud storage slug, detects the real unit name (e.g. Unit 1 - Graph Theory), and numbers duplicates neatly.

03

Paced & Safe Downloads

Designed to avoid browser crashes and cloud rate-limits with a 350ms paced queue that keeps disk writes smooth and steady.

04

Zero Account Setup

No secondary logins or new accounts. SuperK runs securely in your browser and automatically detects your active classroom session.

05

Private & Client-Side

No telemetry, no analytics, no servers of our own — requests go only to your university's own portal services, and your authentication token is never sent to us.

06

Built-in Quick Filter (⌘K / Ctrl+K)

Instant debounced search. Type any unit, topic, or document title to filter through hundreds of classroom documents in milliseconds.

Safety & requirements

Install it safely. Update it easily.

Verify the ZIP, check your setup, and know how to update or remove SuperK — before the 30-second install below.

Install from here only

Only install SuperK from this site or the project's own GitHub repository. Fake copies of extensions can steal your data — and your session.

SHA-256 of superk-1.0.0.zip:

b0c759d6580b651f69835647cd445a445efe0a11ed4b5d79f55906272debc0c3

Windows: Get-FileHash superk-1.0.0.zip -Algorithm SHA256 — the hash must match exactly.

Browser or Windows warning? Chrome and Windows sometimes flag an "uncommon" ZIP like this one — that is normal for side-loaded extensions. Verify the SHA-256 above, then keep the file.

Requirements & limits

  • Desktop Chromium browsers only — Chrome, Brave, Edge, Opera, Vivaldi, or Arc.
  • Not supported on Firefox, Safari, or phones.
  • Needs an active classroom login while you use it.
  • Works only for Parul University's elearning portal — built and tested on the developer's own enrolled courses.

Update & remove

  • Update: download the new ZIP, extract it over your existing folder, then click Reload on chrome://extensions.
  • Remove: right-click the SuperK icon, or open chrome://extensions, and choose Remove from Chrome.
  • Version history: v1.0.0 — first public release (Oct 2026). See the Changelog or full history on GitHub.
  • Startup note: after a restart Chrome may show a "Disable developer mode extensions" bubble — close it with the X. Clicking Disable would switch SuperK off.

No mystery permissions

What Chrome asks for — and why

Chrome lists permission warnings when you side-load an extension. Here is every item SuperK asks for, and exactly what it is used for.

Standard permissions

  • activeTab — read the classroom tab you are on, only when you open SuperK.
  • scripting — run the one-time scan that lists the files on the page you are viewing.
  • downloads — hand the PDFs and ZIPs to Chrome's own download manager.
  • storage — keep your options on your own device, nothing more.

Site access (3 hosts)

  • elearning.paruluniversity.ac.in — the university's classroom portal itself.
  • platform-api.edorer.com — the university's own API that lists your enrolled files.
  • *.digitaloceanspaces.com — the cloud storage where the university hosts the PDFs.

What it never asks for

  • No "read all sites" access — only the three hosts above.
  • No passwords, history, bookmarks, or payment data — ever.
  • Full details are in the Privacy Policy.

Quick answers

Asked by every student

Straight answers, no fine print.

Why did my ZIP download say "Too Big"?

Your browser tab only has so much RAM. SuperK measures every file first, and past ~150 MB it skips the single ZIP and downloads the files individually instead — same PDFs, zero crashes.

Why does it say "No Auth" or fallback mode?

Your classroom login session hadn't loaded when SuperK scanned. Refresh the Edorer classroom tab once so the session token loads, then reopen SuperK.

Which browsers work?

Chrome, Brave, Edge, Opera, Vivaldi, and Arc — any Chromium browser that supports Manifest V3 extensions.

Is this official?

No. SuperK is an independent student project — not affiliated with, asked for, or endorsed by Parul University or Edorer. Nobody at the university approved it.

Is it allowed? Will I get in trouble?

Honest answer: we can't promise. Your university's portal rules still apply to you, and SuperK doesn't change them. Use it at your own responsibility, for your own enrolled subjects and personal study. See the Terms & Conditions.

Does it store my password?

No. SuperK never sees or saves your password. It reads the session token your browser already holds, in memory only, to ask the university's API for your own file list — nothing is stored on any server of ours.

Does it work on mobile or Firefox?

No — desktop Chromium browsers only (Chrome, Brave, Edge, Opera, Arc). Firefox, Safari, and phones aren't supported.

How do I update it?

Download the new ZIP, extract it over your existing folder, then click Reload on chrome://extensions. Your extension stays set up — nothing else to do.

Is it really free?

Yes — free and open source (MIT). No account, no paywall, no tracking. If SuperK saves you time, tips are optional and go straight to development.

What if it stops working?

The university can change its portal at any time, and that can break SuperK until it is updated. If your subject list stops loading or downloads fail, report it on the feedback page — fixes ship quickly.
