Quick install via unpacked extension

Five steps, about thirty seconds.

Download

Download superk-1.0.0.zip from this site, then unzip it somewhere safe — e.g. Documents/SuperK.

Open extensions page

Chrome: chrome://extensions
Brave: brave://extensions
Edge: edge://extensions
Opera: opera://extensions
Vivaldi: vivaldi://extensions
Arc: chrome://extensions

Enable Developer mode

Toggle the Developer mode switch in the top-right corner of the extensions page.

Load unpacked

Click Load unpacked (top-left), then pick the extracted folder — the one containing manifest.json.

Pin SuperK

Click the puzzle icon in your toolbar, then pin SuperK so it's one click away.

Common troubleshooting

The fixes for almost every problem students hit.

"Manifest file is missing or unreadable"

You picked the ZIP file itself, or the wrong folder. Unzip superk-1.0.0.zip first, then in "Load unpacked" select the folder that contains manifest.json.

The popup says "Page bridge is outdated — refresh tab"?

This happens if you reloaded the extension while the LMS tab was already open. Press F5 / Refresh on your LMS tab and reopen SuperK.

The popup says "No Auth" or falls back to scan mode

Your classroom login session had not loaded when SuperK scanned. Refresh the classroom tab once so the session token loads, then reopen SuperK.

I can't see the SuperK icon

Click the puzzle icon in the toolbar, find SuperK in the list, and pin it so it stays visible.

Where do downloaded files go?

Everything SuperK saves goes to your browser's Downloads/Parul/ folder, organised by subject and topic.

A "Disable developer mode extensions" bubble appears at startup

That is a normal Chrome warning for side-loaded extensions. Close it with the X — do not click Disable, which would switch SuperK off.

What if a subject has over 150MB of PDFs?

SuperK has an automatic memory safeguard. Past ~150MB it skips the single ZIP and downloads the files individually instead — same PDFs, zero browser crashes.

Chrome or Windows warns about the ZIP

Chrome and Windows flag "uncommon" files like this one — that is normal for side-loaded extensions. Verify the SHA-256 listed on the home page and keep the file if it matches.

SuperK stopped working after a portal update

The university can change its portal at any time, which breaks SuperK until it is updated. Please report it — details like the error text and subject name make the fix quick.

Update and remove

SuperK stays set up between versions — you only replace the folder once.

Update to a new version

Download the new ZIP, extract it over your existing folder so the files are replaced, then open chrome://extensions and click Reload on SuperK. Your settings are kept.

Remove SuperK

Open chrome://extensions (or brave://extensions / edge://extensions / opera://extensions) and choose Remove on SuperK. You can also right-click the toolbar icon and select Remove from Chrome. Deleting the extracted folder also works.

Clear SuperK's stored data

Removing the extension clears its chrome.storage.local data with it. Your downloaded PDFs in Downloads/Parul/ are ordinary files — delete them yourself whenever you like.
