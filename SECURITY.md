# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | Yes — current release |
| Older   | No                 |

## Reporting a Vulnerability

Please report security issues **privately** — not in public GitHub issues.

- **Email:** `kabaligamer.dev@proton.me` — use the subject line `SuperK security`.
- **Or:** open the repo's **Security → Report a vulnerability** tab, which uses GitHub's private vulnerability reporting: <https://github.com/kabaliGamer-Dev2/superk/security/advisories/new>

Please include: what you found, steps to reproduce, and the impact you believe it has. Mentioning your browser, OS, and the extension version (visible on `chrome://extensions`) helps a lot.

## What to Expect

- Acknowledgement within **72 hours** (best effort — this is a solo student project).
- A fix, mitigation, or clear explanation as quickly as the issue allows. With your permission, you will be credited once a fix ships.
- Please allow a reasonable window for a fix before any public disclosure.

## Scope

**In scope:** the SuperK extension in this repository, and the landing website at `https://superk-official.web.app`.

**Out of scope:** the university's own systems (report those to the university), attacks against third parties, social engineering, and anything requiring access to someone else's device.

## Good-Faith Research

Testing limited to your own browser, your own account, and your own data is welcome under this policy. Do not access, modify, or download other people's data while testing.
